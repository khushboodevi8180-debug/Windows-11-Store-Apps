Windows 11 Store Apps

A public repository for hosting HTML-based apps and games for the Windows 11 Web OS Microsoft Store.

📌 About

This repository provides downloadable ZIP packages for apps and games that can be installed through the Windows 11 Web OS Microsoft Store.

App packages are distributed through GitHub Releases.

✨ Features

- 📦 Downloadable ZIP packages
- 🎮 HTML-based games and applications
- 🖼️ Support for custom app icons
- 📁 Organized app files and assets
- 🔄 Versioned releases for app updates
- 🏪 Integration with the Windows 11 Web OS Microsoft Store

📥 Installation

1. Open the Windows 11 Web OS Microsoft Store.
2. Find the app you want to install.
3. Select Install.
4. Follow the Store's installation instructions.

📦 App Distribution

Each app can be published as a ZIP package through GitHub Releases.

The Store repository configuration specifies details such as:

- App name
- App description
- Version
- Category
- ZIP download URL
- Entry HTML filename
- App icon path

🔗 Releases

Visit the "Releases" (https://github.com/khushboodevi8180-debug/Windows-11-Store-Apps/releases) page to find published app packages.

⚠️ Notes

- App packages must follow the expected ZIP folder structure.
- The configured entry HTML file must exist inside the ZIP package.
- Required assets, including icons, must be included at their configured paths.
- Only install packages from sources you trust.
